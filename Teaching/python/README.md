# Ejercicios de Python

Hojas de ejercicios utilizadas como apoyo docente: fundamentos, control de flujo, funciones, colecciones y NumPy/Pandas.

La [semana 1](exercises/Ejercicios_Semana_1/) incluye presentaciones, apuntes y un tutorial ejecutable sin dependencias externas.

Los cuadernos de las semanas 2 a 4 están en [exercises/](exercises/). Son plantillas para completar: las celdas vacías son intencionadas, no soluciones perdidas.

Instalar las dependencias con `python -m pip install -r ../requirements.txt`, desde esta carpeta. Abrir `jupyter lab` y seleccionar un cuaderno. Ver [la guía docente](../README.md) para el contexto y alcance de la revisión.
