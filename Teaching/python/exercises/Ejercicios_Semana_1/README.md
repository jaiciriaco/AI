# Semana 1 — Introducción a IA, Big Data y Python

Material docente de Jaime Ciriaco para las primeras clases. Presentaciones y documentos de contexto se complementan: leer cada diapositiva y después su explicación.

## Contenido y orden recomendado

1. [Presentación de IA y Big Data](Teoría_IA_y_BigData_PPT.pdf) y [documento de contexto](Teoría_IA_y_BigData_Doc.pdf).
2. [Presentación de Python](Iniciación_Python_PPT.pdf) y [documento de contexto](Iniciación_Python_Doc.pdf).
3. [Tutorial práctico de Python](tutorial_python.py): cadenas, variables, operadores, condicionales, bucles y funciones.
4. Continuar con los [ejercicios de las semanas 2 a 4](../).

## Ejecutar el tutorial

Con Python 3, desde esta carpeta:

```bash
python tutorial_python.py
```

No requiere bibliotecas externas, credenciales ni archivos de datos. Hay dos bucles interactivos: escribir `salir` en el primero y `caracol` en el segundo para continuar. También se pueden ejecutar los bloques individualmente en un editor.
