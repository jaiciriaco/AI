# Fundamentos de Data Science

Seis lecciones autocontenidas con datos sintéticos:

1. Álgebra lineal.
2. Cálculo y optimización.
3. Probabilidad.
4. Estadística descriptiva e inferencia.
5. Hipótesis y A/B testing.
6. Mini proyecto integrador.

Instalar las dependencias con `python -m pip install -r ../requirements.txt`, desde esta carpeta. Ejecutar `jupyter lab` desde esta carpeta y abrir cada notebook con un kernel nuevo. No se necesitan archivos de datos externos.

Las [soluciones](soluciones/) se mantienen separadas para poder trabajar primero los ejercicios. El código de las seis lecciones se ejecutó en orden durante la revisión. Las aproximaciones estadísticas y límites se detallan en [Teaching/README.md](../README.md).
