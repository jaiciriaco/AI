# Soluciones de estadística

Soluciones de referencia para las [lecciones](../). Incluyen álgebra, cálculo, probabilidad, estadística, A/B testing y el proyecto integrador.

Instalar las dependencias con `python -m pip install -r ../../requirements.txt`, desde esta carpeta. Abrir los cuadernos con `jupyter lab` y ejecutar en orden desde un kernel nuevo. Cada solución es independiente y genera sus datos sintéticos.

Se ejecutaron las celdas de los seis cuadernos durante la revisión. Son soluciones didácticas posibles, no la única forma de resolver los ejercicios.
