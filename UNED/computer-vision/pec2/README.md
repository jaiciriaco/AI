# PEC2 — Visión artificial clásica

Ejercicios de líneas, características, homografías y seguimiento.

[Memoria original](report.pdf). Los scripts `pec2_ej*.py` corresponden a los apartados de la práctica.

## Uso

Instalar las dependencias con `python -m pip install -r ../requirements-classical.txt`, desde esta carpeta. Ejecutar el script elegido desde esta carpeta, por ejemplo:

```bash
python pec2_ej1a.py
```

Los recursos se leen de `data/`. Se necesita un entorno de escritorio para las ventanas OpenCV; `pec2_ej3b.py` y `pec2_ej3c.py` utilizan cámara. Algunos ejercicios guardan resultados en el directorio de trabajo o en `data/`.

Se revisó la sintaxis. No se ejecutaron interfaces ni cámara. Las imágenes de ejemplo no se presentan como creación propia; se conserva el contexto académico.
