# PEC1 — Visión artificial clásica

Ejercicios de procesamiento, transformaciones, calibración, segmentación e interacción con cámara.

[Memoria original](report.pdf). Los scripts `pec1_Ej*.py` corresponden a los apartados de la práctica.

## Uso

Instalar las dependencias con `python -m pip install -r ../requirements-classical.txt`, desde esta carpeta. Ejecutar el script elegido desde esta carpeta, por ejemplo:

```bash
python pec1_Ej2_a.py
```

Los recursos se leen de `data/`. Se necesita un entorno de escritorio para las ventanas OpenCV; `pec1_Ej4.py` utiliza cámara. Algunos ejercicios guardan resultados en el directorio de trabajo o en `data/`.

La fotografía de `data/face/` y los dibujos de `data/DibujosNPT/` se mantienen fuera de GitHub. Sus ejercicios requieren esas entradas locales, que estaban en el ZIP original.

Se revisó la sintaxis. No se ejecutaron interfaces ni cámara. Las imágenes de ejemplo no se presentan como creación propia; se conserva el contexto académico.
