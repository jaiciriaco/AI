## Criterio editorial

Se conservaron los trabajos y las memorias originales; los PDF no se modificaron. Se eliminaron copias exactas, enunciados independientes, material de referencia ajeno, salidas de notebooks y pesos regenerables. Los cambios de código se limitan a rutas portables y organización de datos. Los resultados de las memorias son históricos, no resultados obtenidos durante esta revisión.

No se atribuyen a este repositorio los derechos de los datasets, plantillas o bibliotecas externas. Las referencias incluidas en los trabajos se conservan. No se añade una licencia global a estos materiales académicos.
