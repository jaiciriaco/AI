# PEC2 — Clasificación de noticias

Comparación de enfoques de procesamiento del lenguaje natural sobre AG News (World, Sports, Business y Sci/Tech).

- [Notebook](PEC2_PLN_Jaime_Ciriaco.ipynb).
- [Memoria original](report.pdf).

Instalar las dependencias con `python -m pip install -r ../requirements-nlp.txt`, desde esta carpeta. Abrir `jupyter lab` desde esta carpeta y ejecutar en orden. Se necesita acceso a los proveedores para descargar datos y modelos; las cachés y pesos no se versionan.

El código usa PyTorch, Transformers y Datasets. Entrenamientos y descargas no se ejecutaron durante esta revisión; los resultados del informe son los de la entrega.
