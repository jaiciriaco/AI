# Cuadernos de aprendizaje automático

Ocho prácticas: sesgo-varianza I/II, LDA/QDA/RDA, clasificación no paramétrica, remuestreo, reducción dimensional, outliers y regresión Diabetes.

Instalar las dependencias con `python -m pip install -r ../requirements.txt`, desde esta carpeta. Ejecutar `jupyter lab` desde esta carpeta. Los datos locales se leen de `../data/`; Iris y Diabetes se obtienen de scikit-learn. Usar un kernel nuevo por práctica.

Consultar [VALIDATION.md](../../VALIDATION.md) para saber qué cuadernos se ejecutaron y [el README de la asignatura](../README.md) para las limitaciones metodológicas. Las salidas se han limpiado para evitar gráficos y resultados obsoletos.
