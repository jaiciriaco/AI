# Scripts de prácticas

| Script | Trabajo |
| --- | --- |
| `movielens_onehot_Jaime.py` | Preparación one-hot de géneros de MovieLens |
| `naivebayes_practica_MAA_JaimeCiriaco.py` | Naive Bayes sobre Iris y Bank Marketing |
| `generate_association_rules_Jaime.py` | Generación de reglas de asociación |
| `Apriori_comparisons_Jaime.py` | Comparación de configuraciones Apriori |

Instalar las dependencias con `python -m pip install -r ../requirements.txt`, desde esta carpeta. Ejecutar desde esta carpeta, por ejemplo `python movielens_onehot_Jaime.py`.

Los scripts consultan GroupLens/UCI y necesitan red. Las salidas se escriben en el directorio de ejecución; usar una copia para conservar resultados anteriores. La instantánea `../data/onehot_movies.csv` se almacena una sola vez y no sustituye automáticamente las descargas que realiza el código.

Sintaxis revisada; las consultas externas no se ejecutaron.
