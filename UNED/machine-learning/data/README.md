# Datos de las prácticas

- `dataset_1.csv` a `dataset_6.csv`: entradas de regresión compartidas por las dos prácticas de sesgo-varianza.
- `Mall_Customers.csv`: entrada para detección de outliers.
- `onehot_movies.csv`: instantánea de la transformación de MovieLens aportada con las prácticas.

Se conserva una copia de cada tabla. Los notebooks las leen desde esta ubicación; los scripts de MovieLens pueden volver a descargar y generar datos por su cuenta.

Estos datos forman parte de los materiales utilizados en las prácticas. Su inclusión no implica autoría propia ni una licencia global del repositorio; se mantienen los derechos y condiciones de sus fuentes.
